# 连续扫描

在 `ix100/wifi/` 中执行：

```powershell
python src/scan_interactive.py --output-dir output --config config/ix100.local.ini
```

程序连接扫描仪并启动一个连续作业，随后自动等待纸张。有纸便扫描并保存一张 BMP，保存后继续等纸。彩色、灰度、黑白分别保存为 24、8、1 位。启动前已经放好纸也会自动扫描。

可加 `--dpi INTEGER`、`--color-mode color|gray|mono`、`--overscan`／`--no-overscan` 覆盖 INI 设置；缺省为 300 DPI、彩色、开启 overscan。同一个作业内使用相同设置。

`--output-dir DIR` 指定保存目录；省略时使用 INI `[scan] output` 的父目录。目录按原值使用，不执行 `scan_direct.py` 的时间格式展开。每张文件名包含时间戳和会话内序号，例如 `ix100-20260913-120000-000-0001.bmp`。输出保存最终尺寸对应的全部有效像素，不反色、不裁剪。

按回车请求结束：等纸时直接收尾；正在扫描时，先读完并保存当前页，再结束作业并释放设备。按 Ctrl+C 中止；扫描或保存失败也会退出并尽力结束作业、释放预约。

入口要求交互终端。键盘输入和扫描操作由同一线程串行处理，扫描时输入的回车会留待当前页保存后处理。页间保持同一个作业和设备预约，退出时统一收尾。

当前连续作业实现尚未进行真机验证；灰度和黑白的未压缩响应格式与极性也尚未真机确认。
