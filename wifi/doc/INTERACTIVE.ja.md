# 連続スキャン

[简体中文](INTERACTIVE.md) | [English](INTERACTIVE.en.md) | [日本語](INTERACTIVE.ja.md)

`ix100/wifi/` で実行します：

```powershell
python src/scan_interactive.py --output-dir output --config config/ix100.local.ini
```

機器に接続して 1 つの連続ジョブを開始し、自動で用紙を待ちます。用紙があればスキャンして BMP を 1 枚保存し、再び用紙を待ちます。カラー・グレースケール・白黒はそれぞれ 24・8・1 ビットで保存します。起動前に挿入した用紙も自動でスキャンします。

`--dpi INTEGER`、`--color-mode color|gray|mono`、`--overscan` / `--no-overscan` で INI 設定を上書きできます。既定は 300 DPI、カラー、overscan 有効です。同じジョブ内では設定を共用します。

`--output-dir DIR` で保存先を指定し、省略時は INI の `[scan] output` の親ディレクトリを使います。ディレクトリはそのまま使用し、`scan_direct.py` の時刻展開は行いません。ファイル名はタイムスタンプとセッション内の連番を含み、例は `ix100-20260913-120000-000-0001.bmp` です。最終寸法に対応するすべての有効ピクセルを保存し、色反転・切り取りは行いません。

Enter で終了を要求します。用紙待機中なら即座に終了処理を行い、スキャン中なら現在のページを読み取り・保存してからジョブを終了し機器を解放します。Ctrl+C は中断します。スキャン・保存に失敗した場合も終了し、可能な限りジョブの終了と予約の解放を行います。

対話型端末が必要です。キーボード入力とスキャンは同じスレッドで順に処理します。スキャン中の Enter は現在のページ保存後に処理します。ページ間は同じジョブと予約を維持し、終了時にまとめて後処理します。

現在の連続ジョブ実装は実機未検証です。非圧縮グレースケール・白黒の応答形式と極性も実機未確認です。
