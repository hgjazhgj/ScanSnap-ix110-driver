# Universal third-party driver for ScanSnap iX100 / iX110

[简体中文](README.md) | [English](README.en.md) | [日本語](README.ja.md)

I bought a portable scanner, possibly the only portable scanner currently on the market with a Type-C port.  
After buying it, I found that its official driver was a pile of crap: bloated, coupling hardware drivers for different models with subsequent software image processing (perhaps that makes it easy to use and popular among Japanese wage slaves who left high school to start working). Worse, the essential hardware driver only offers JPG and PDF, two lossy compressed formats, which I cannot accept.  
In fact, the hardware itself can output uncompressed images.

This project aims to let everyone who owns this device obtain original image data without downloading or installing the official application.  
This consumer scanner is not a professional camera: its hardware does not provide raw sensor output, only demosaiced BMP data.

The scanner cost me about JPY 24,000, while the AI used for the reverse engineering requires at least a JPY 30,000 ChatGPT Pro 20x subscription.  
Getting all the modules working correctly and matching the intended behavior also requires substantial manual guidance from a developer with relevant expertise, along with repeated manual management of the hardware state during testing.  
I sincerely look forward to the day when saying “give me a clean reverse-engineering result” is enough to get it right in one go.

Three independent components are collected here. Each component keeps its runtime source in `src/`, documentation in `doc/`, and Python dependencies in its root directory.

| Component | Purpose | Instructions |
| --- | --- | --- |
| `usb/` | USB single-page and continuous scanning to BMP | [USB scanning](usb/README.en.md) |
| `wifi/` | Wi-Fi single-page, panel-triggered and continuous scanning to BMP | [Wi-Fi scanning](wifi/README.en.md) |
| `wifi-setup/` | Read and configure scanner wireless settings over USB | [Wi-Fi setup](wifi-setup/README.en.md) |

Python 3.11 or later is required. Enter the chosen component directory and follow its README to install dependencies and prepare the driver or configuration. For example, view offline help from this directory:

```powershell
python -B usb/src/scan_direct.py --help
python -B wifi/src/scan_direct.py --help
python -B wifi-setup/src/setup_cli.py --help
```

Almost everything else in this repository was generated by AI, with a few edits and deletions.
